# each mistake names itself instead of silently doing nothing

a window that is not a time: WINDOWS entry 'morning' must be a start time as HHMM, e.g. '0830'
a blocked window that does not exist: UNAVAILABLE.wed.windows must be "all" or a list of your call windows ['0900']
a weekday that is not one: UNAVAILABLE weekday 'wednesday' is not one of ['mon', 'tue', 'wed', 'thu', 'fri', 'sat', 'sun']
a block with no reason: UNAVAILABLE.fri needs a non-empty 'reason'
